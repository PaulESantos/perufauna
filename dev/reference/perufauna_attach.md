# Attach Core Packages in perufauna

Attaches all core member packages of the perufauna ecosystem
(`avesperu`, `perumammals`, `citesperu`, `perufaunads004`) that are not
yet loaded onto the search path.

## Usage

``` r
perufauna_attach()
```

## Value

Invisible character vector of newly attached packages.

## Examples

``` r
# \donttest{
perufauna_attach()
# }
```
