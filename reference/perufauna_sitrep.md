# Situation Report on perufauna and Core Biodiversity Packages

Prints a diagnostic overview of the current R session, the version of
`perufauna`, and the installation status and version of each core member
package (`avesperu`, `perumammals`, `citesperu`, `perufaunads004`).

## Usage

``` r
perufauna_sitrep()
```

## Examples

``` r
# \donttest{
perufauna_sitrep()
#> ── R Environment ───────────────────────────────────────────────────────────────
#> • R: 4.6.1
#> • perufauna: 0.1.0.9000
#> ── Core Biodiversity Packages ──────────────────────────────────────────────────
#> • avesperu         (v0.1.1)
#> • perumammals      (v0.0.0.2)
#> • citesperu        (v0.1.0)
#> • perufaunads004   (v0.1.0)
# }
```
